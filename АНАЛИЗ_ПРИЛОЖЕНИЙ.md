# Анализ приложений практики — 31.10.2026

## Вывод

Проекты соответствуют тематике пройденных дисциплин и остаются небольшими учебными работами. Flask/CLIPS решает задачу экспертной системы, Expo — мобильных заметок, Python-скрипт — анализа анкет. Это сопоставление с предоставленным списком курсов и текстами кейсов, а не подтверждение по полным рабочим программам всех дисциплин.

Код подготовлен к загрузке в SyTestCases3. Работа КЗ5 в целом ещё не завершена: нужны реальные ответы участников, выводы и презентация. Native-проверка заметок на Android/iOS остаётся отдельным этапом.

## Оценки по 10-балльной шкале

Оценки экспертные, не прогноз баллов преподавателя. 10 означает выполнение требований с убедительной проверкой и без существенных известных пробелов; 8–9 — хороший учебный результат с оговорёнными ограничениями; 5–7 — частичную готовность. «Стиль» оценивает читаемость и уместность решений, а не происхождение кода.

## Проверки

- КЗ3: 26 случаев pytest, включая исходные 20; настоящий HTTP-запуск Flask; ввод и результат диагностики, база знаний, экраны 390 и 1280 px.
- КЗ4: TypeScript; unit-тесты дат, времени, поиска, localStorage, SQL-запросов и инициализации; проверка сохранности JSON при ошибке записи. SQL исполняется настоящим SQLite Node.js, native-интерфейсы заменены тестовыми адаптерами.
- КЗ4: web export, Android Hermes export (не APK и не запуск устройства) и браузерная проверка CRUD, поиска, перезагрузки, независимости режимов, отмены/подтверждения удаления, повреждённых данных и отказа записи. Реальный Android/iOS не запускался.
- КЗ5: unittest на формулу SUS, границы, контрольные ответы, пустую/неверную CSV, отчёт при отсутствующем SEQ и сохранение прежнего отчёта при ошибке.
- Отдельный ревьюер проверил исходный код и исправления; замечания по сохранению файлов, поздней навигации и пустой CSV учтены.

Команды для повторения приведены в README каждой работы. Фактический протокол последнего прогона сохраняется в `ПРОВЕРКИ.txt`.

## Стиль кода

Сохранена простая структура без лишних сервисных слоёв и новых библиотек в рабочем приложении. Playwright добавлен только для воспроизводимого браузерного теста. Комментарии в прикладном коде короткие и на русском; они объясняют форматы данных и поведение хранения. Отключённая трассировка CLIPS имеет реальное диагностическое назначение.

Намеренные ошибки, фиктивные TODO и вымышленные следы разработки не добавлялись. По внешнему виду кода нельзя доказать его авторство. Для самостоятельной защиты нужно понимать цепочку правил, различия SQLite/JSON/localStorage, формулу SUS и ограничения небольшого исследования.

Лицензия исходного шаблона Expo сохранена. Демонстрационные данные, тестовые ответы и проверочные скрипты не выдаются за результаты настоящих пользователей.

## Что остаётся пользователю

1. Проверить native-хранилища на телефоне по `ПРОВЕРКА_ANDROID.md`.

3. Провести юзабилити-тест, проверить обезличенные ответы, подготовить презентацию и ссылку на неё.
4. Перенести актуальные ссылки SyTestCases3 в отчёт. Word/PDF-документы в этой работе не изменялись.
