# Практика, 8 семестр

Три проекта по учебной практике: экспертная система для поддержки 1С, приложение заметок для встреч и материалы проверки его удобства.

| Проект | Содержание | Стек |
|---|---|---|
| [2026-task3](2026-task3/README.md) | Диагностика проблем с 1С: возможные причины, приоритет обращения и объяснение вывода | Python, Flask, CLIPS |
| [2026-task4](2026-task4/README.md) | Создание, редактирование, поиск и удаление заметок о встречах | TypeScript, React Native, Expo |
| [2026-task5](2026-task5/README.md) | Сценарий юзабилити-теста, анкета и обработка CSV | Python |

## Демо

[Заметки встреч — открыть в браузере](https://lightninggo.github.io/SyTestCases3/2026-task4/web-demo/)

В демо есть пять примеров записей. Данные сохраняются в браузере через localStorage. В мобильном приложении используются SQLite и JSON-файлы; хранилища независимы, переключение доступно в настройках.

Экспертная система запускается локально через Flask. Команды запуска и тестов приведены в README каждого проекта.

## Ограничения

Правила экспертной системы и коэффициенты уверенности заданы вручную. Это учебный прототип, без проверки точности на реальных обращениях.

Для заметок проверены веб-версия и логика хранения в автоматических тестах. Запуск на Android и iOS пока не подтверждён проверкой на устройстве. Личные ответы участников юзабилити-теста в репозитории не публикуются.
