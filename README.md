# Практика, 8 семестр

Здесь три задачи: поддержка 1С, заметки для встреч и тест удобства этих заметок.

- [2026-task3](2026-task3/README.md) — экспертная система на Flask и CLIPS. По описанию проблемы предлагает причины и показывает, какие правила сработали.
- [2026-task4](2026-task4/README.md) — приложение заметок на Expo. Можно создавать, менять, искать и удалять записи.
- [2026-task5](2026-task5/README.md) — материалы теста и скрипт для разбора ответов. Самих результатов пока нет.

## Демо заметок

[Открыть в браузере](https://lightninggo.github.io/SyTestCases3/2026-task4/web-demo/)

Для первого знакомства ничего устанавливать не нужно. В браузере есть пять примеров записей. На телефоне через Expo Go используются SQLite и файлы, а в браузере — localStorage. Это разные способы хранения.

Flask-приложение нужно запускать отдельно на компьютере, GitHub Pages его не запускает. Команды есть в README каждой задачи.

## Что заливать

В корень `SyTestCases3` идут эти три папки и файлы рядом с ними. `.nojekyll` тоже нужен: без него при публикации через Jekyll могут пропасть ресурсы из `_expo`.

Не добавлять `.venv`, `2026-task4/node_modules`, кэши и личные ответы участников. Это уже указано в `.gitignore`. А вот `web-demo/assets/node_modules` удалять нельзя — там картинки готовой сборки, не установленные зависимости.

Для Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. После успешного развёртывания открыть ссылку выше без входа в GitHub и проверить, что список заметок появился.

Ссылки для отчёта:

- [КЗ3](https://github.com/LightningGo/SyTestCases3/tree/main/2026-task3)
- [КЗ4](https://github.com/LightningGo/SyTestCases3/tree/main/2026-task4)
- для КЗ5 нужна ссылка на презентацию, когда будут ответы и выводы.
