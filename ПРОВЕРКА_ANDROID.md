# Запуск заметок на Android

Проект использует Expo SDK 57. Для запуска нужен Node.js 24 и версия Expo Go с поддержкой этого SDK. Совместимые версии доступны на [странице Expo Go](https://expo.dev/go).

## Телефон

Команды из корня репозитория:

```powershell
Set-Location 2026-task4
npm.cmd ci
npm.cmd start
```

Телефон и компьютер подключаются к одной Wi-Fi-сети. Приложение открывается в Expo Go по QR-коду из терминала. При недоступности локального соединения доступен запуск через туннель:

```powershell
npx.cmd expo start --tunnel
```

Туннелю нужен интернет; Expo может запросить установку дополнительного пакета. Сервер останавливается сочетанием Ctrl+C.

На телефоне оба хранилища изначально пустые. Пять демонстрационных записей добавляются только в веб-версии.

## Эмулятор

Используется Android Emulator из Android Studio. После установки Android SDK и создания виртуального устройства в Device Manager:

1. Запустить виртуальное устройство.
2. Выполнить `npm.cmd start` в каталоге `2026-task4`.
3. Нажать `a` в терминале Expo.

[Настройка эмулятора в документации Expo](https://docs.expo.dev/workflow/android-studio-emulator/).

## Проверка хранилищ и интерфейса

| Действие | Ожидаемый результат |
|---|---|
| Создать запись в SQLite | Запись появляется в списке и открывается |
| Изменить заголовок и текст, нажать «Сохранить» | Поля обновляются, дубль не создаётся |
| Найти запись по слову, дате и времени | В списке остаются совпадения |
| Полностью закрыть приложение и открыть снова | Запись сохранена |
| Выбрать файловый режим и создать другую запись | У режима свой список |
| Закрыть и снова открыть приложение | Файловый режим и запись сохранены |
| Вернуться в SQLite | Исходная запись на месте |
| Отменить удаление, затем подтвердить его | Отмена сохраняет запись, подтверждение удаляет |
| Ввести пустой заголовок, дату 31.02.2026 или время 24:60 | Форма показывает ошибку |

Для воспроизводимости проверки фиксируются модель устройства, версии Android и Expo Go, дата и результаты шагов.

## Статус

Запуск на реальном Android-устройстве или эмуляторе пока не проверен. Экспорт Android-бандла выполнен; он не включает установку APK и проверку native-модулей на устройстве.
